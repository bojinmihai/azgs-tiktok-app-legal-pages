TikTok integration — privacy notice

1. Who operates the integration

AZ Grand Solutions operates the internal AZGS local workspace. For privacy, access or deletion requests contact info@azgs.nl. This notice concerns data processed through its TikTok integration and visitors to these documentation pages.

2. Data accessed

After account authorization, the connector uses the scope user.info.basic for the TikTok account identifier and display name. The scope video.list is used to retrieve public video identifiers, titles, creation dates, sharing URLs, and available view, like and comment counts. The connector also stores an access token, the account identifier/display name and connection-verification metadata. The current integration does not request private messages, passwords or payment details.

3. Purposes and authorization

Information is used to verify the connected business account, display its public content, support business-content analysis requested by authorized operators, and keep connection and operation records. Access requires the account holder's authorization and project-level access settings. It is not used by this integration for advertising targeting, sale of data or unrelated account access. Authorization can be withdrawn; this stops future authorized API access but does not itself erase earlier local records.

4. Storage and access

Connector credentials and discovered account metadata are stored locally on the Windows PC, encrypted with Windows DPAPI for the current Windows user. Tokens are used by the backend to call TikTok and are not intentionally included in AI prompts or these public pages. Retrieved data can be retained in local conversation history, operation records, monitoring results and project memory. Local project files and logs do not all receive the same DPAPI encryption as the credentials.

5. AI providers and other recipients

If an operator requests AI analysis, relevant retrieved information can be sent to the configured providers of the AI participants used for that task: OpenAI (Codex), Anthropic (Claude), Google/Antigravity (Gemini), or Perplexity. The actual recipients depend on the task and selected participants. Their retention, processing locations and terms are governed by the operator's accounts with those providers; processing may occur outside the user's country. Access tokens are not sent as task content. TikTok receives authenticated API requests necessary for the connection.

6. Retention and deletion

Credentials are retained until replaced or disconnected. Existing local records are retained until the operator removes the relevant history, project data, monitoring records or backups; there is no automatic fixed deletion period in the current application. Disconnecting a connector is not deletion of previous records. To request access, correction or deletion, email info@azgs.nl identifying the TikTok account and the data concerned, without sending passwords or tokens. The operator will verify the request, remove data under its control as appropriate and explain any retention requirements. Copies already processed by an external AI provider are subject to that provider's controls and terms; deletion from the local PC does not automatically delete them.

7. Revocation

Use the TikTok disconnect control in AZGS local to remove local connector credentials. Also remove the app's authorization in TikTok's account/app-permission controls to revoke provider-side access. You may stop using the integration at any time. Contact the operator for help locating and deleting retained local data or exercising applicable privacy rights. Applicable law may also provide a right to contact a competent data-protection authority.

8. These public pages

These static pages contain no analytics scripts, tracking pixels, forms or TikTok account data. GitHub Pages serves them and may process technical request information such as IP addresses under GitHub's privacy statement. A contact-email link opens the visitor's email client; no message is sent automatically.

9. Changes

We update this notice when the integration's actual data uses change. New permissions or uses may require renewed authorization. For the current capabilities see application information.
