AZGS local TikTok integration

AZGS local is an internal Windows workspace operated by AZ Grand Solutions for its authorized team. The TikTok integration is intended to let an authorized administrator view the firm's TikTok profile and public videos from the local application.

The integration is being configured in TikTok Sandbox. It is not a public sign-up service. This page does not mean TikTok has approved the application or that account authorization is complete.

What it can do

With account authorization, the connector reads basic profile information and a list of public videos, including video links and available engagement counts. The requested scopes are user.info.basic and video.list.

The current TikTok connector does not publish, schedule, edit or delete TikTok videos, read private messages, or run advertising campaigns. Other services connected to AZGS local are separate integrations.

Application documents

Read the TikTok application terms and TikTok integration privacy notice. For support, authorization or deletion questions contact info@azgs.nl.

Optional approved browser workflow

Separately from the read-only TikTok API connector, AZGS local now offers an optional browser executor using the official Claude Code and Claude in Chrome integration. An authorized operator can review and approve an exact package of account, content, media files and publishing times. The executor may then prepare drafts, upload, publish or schedule that approved content through the platform website where the account and platform support it. Login, site permissions, CAPTCHA and new agreements can require manual action. This does not add TikTok API publishing scopes or imply TikTok approval of a Direct Post API client.

The browser workflow sends task instructions, approved media where needed, and relevant visible page information to Anthropic for execution. It uses the existing browser login without intentionally sending passwords or connector tokens as task content. Approved media is copied locally into the browser-task records; these copies and job logs remain until the operator removes them. If a package is executed, its approved content and media are transmitted to the selected social platform and may become public according to the approved action. Cancel an unstarted package in AZGS; already submitted scheduled posts must be checked and cancelled in the platform itself.
